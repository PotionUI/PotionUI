# User Guide

Everything here is written for people generating with PotionUI day to day — no preset authoring or
backend internals assumed. Read in this order, or jump to whatever you need:

- [Getting Started](getting-started.md) — what PotionUI is and how presets, forms, and generation fit together.
- [Generating Images](generating.md) — the Generate page: workspaces, prompts, the form, running and reading results.
- [Presets & Forms](presets-and-forms.md) — what a preset is and how its form maps to what you're generating.
- [History & Tags](history-and-tags.md) — finding past generations, inspecting how something was made, tagging and cleanup.
- [Prompts Workspace](prompts-library.md) — the four reusable prompt-composition libraries in one place.
- [LLM Assistant](llm-chat.md) — the optional AI chat assistant for writing prompts and taking actions.
- [Segments](segments.md) — the composable cards (subject, style, lighting, camera, ...) that build a prompt.
- [Prompt Phrasebook](phrasebook.md) — inline suggestions for terms you use often, so you don't retype or misremember them.
- [Models](models.md) — the installed model files (checkpoints, LoRAs, VAEs, upscalers) and how they connect to presets.
- [Hardware Requirements](hardware-requirements.md) — honest VRAM/RAM numbers for what you're trying to run.
- [Plugins](plugins.md) — optional features an administrator can enable.
- [Administration](admin.md) — the admin-only settings area (not needed for everyday generating).
