Turn a text prompt into a striking, high-quality image. Built for Krea 2, an open image model from Krea designed for speed without giving up image quality. Runs on your own ComfyUI server.

Krea 2 Turbo runs at CFG 1 by default — a distilled/turbo model tuned for a fixed, low-CFG sampling recipe (8 steps, euler/simple) — so the negative prompt has no effect at that scale; that's expected, not a bug.
