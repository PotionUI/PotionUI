A toolbox for audio you already have — starting with **Trim**: cut a window out of a clip by where it starts and how long it should be. Nothing here runs a diffusion model, so there is no prompt, no seed, and no sampler — trim is a sample-accurate cut, read and written straight through `soundfile` without ever decoding the whole file into memory, so it stays fast even on a multi-minute source. The output is always a lossless `.wav`, at the source's own sample rate and channel count (mono stays mono, stereo stays stereo). A window that runs past the end of the clip is clamped to what's actually there rather than erroring; a start at or beyond the clip's own end produces an empty (but still valid) result instead of failing the generation.
