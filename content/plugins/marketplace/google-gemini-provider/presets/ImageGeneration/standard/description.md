Make and edit pictures with Google's Gemini image models (Nano Banana 2, Nano Banana Pro and Nano Banana 2 Lite), without needing a graphics card.

Pick a model, describe the picture and generate. In edit mode, add one or more pictures on the References tab and describe the change you want. The controls you see follow what the chosen model can do, so a setting the model does not offer is simply not shown.

Every picture is made on Google's side and billed to the Google account of the administrator's API key. Your prompt and any pictures you add leave this server to do so.
