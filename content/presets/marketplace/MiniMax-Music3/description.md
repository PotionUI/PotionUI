Generate a full song, vocals and instrumentation together, from a structured caption and optional lyrics — or an instrumental piece with no lyrics field at all. Two sequential stages run on every request: an autoregressive stage samples the song's semantic and residual codes frame by frame (25 fps), then a windowed flow-matching pass turns those into audio a vocoder decodes to 44.1 kHz stereo. One song per generation; runtime is roughly proportional to the requested duration, not a fixed per-request cost — the AR stage alone is on the order of a thousand sequential model forwards for a one-minute song.

**Text-to-music only.** The shipped checkpoint set has no audio encoder, so there is no reference-audio, continuation or in-place-repaint mode — every song is generated from text. The preset has one mode, `Song`.

**What you fill in.** The **Style description** is required: genre, tempo and mood, the vocal character, and the arrangement, in plain text. **Max duration** caps the song's length in seconds (0 lets the model decide); the model ends a song when the lyrics run out, so a cap below the natural ending cuts it short. Switch on **Instrumental (no vocals)** for a piece with no singing; it ignores whatever is in the Prompt box.

**Lyrics go in the Prompt box** and use bracket structure tags — `[verse]`, `[chorus]`, `[bridge]`, and so on — one per line, on their own line; any text sharing a tag's line is dropped rather than sung.

Two obligations still apply regardless of territory: a commercial product's interface must display "MiniMax-Music3" prominently, and a hosted deployment that serves the model to others takes on a safeguards duty (content-safety and misuse-prevention measures, per the license text) rather than the personal/direct-use posture of running it locally for yourself.
