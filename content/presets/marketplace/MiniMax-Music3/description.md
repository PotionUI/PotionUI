Generate a full song, vocals and instrumentation together, from a structured caption and optional lyrics — or an instrumental piece with no lyrics field at all. Two sequential stages run on every request: an autoregressive stage samples the song's semantic and residual codes frame by frame (25 fps), then a windowed flow-matching pass turns those into audio a vocoder decodes to 44.1 kHz stereo. One song per generation; runtime is roughly proportional to the requested duration, not a fixed per-request cost — the AR stage alone is on the order of a thousand sequential model forwards for a one-minute song.

**Text-to-music only.** The shipped checkpoint set has no audio encoder, so there is no reference-audio, continuation or in-place-repaint mode — every song is generated from text. `Song` mode takes a caption plus lyrics; `Instrumental` mode takes the same caption fields with no lyrics field, and always renders with no vocals.

**The caption is a structured document, not a single text box.** Three sections — Global Metadata, Vocal Details (Song mode only), Arrangement — group eleven short fields that the pipeline composes into the one flat caption string the model actually reads. Leave fields blank rather than padding them; only what you fill in reaches the model. Vocal gender & timbre matters more than the others in Song mode — leaving it blank tends to drift the result toward instrumental even with lyrics attached.

**Lyrics use bracket structure tags** — `[verse]`, `[chorus]`, `[bridge]`, and so on — one per line, on their own line; any text sharing a tag's line is dropped rather than sung. See the Lyrics field's own help text for the full tag list and the line-break convention.

Unlike MiniMax-H3's license, its Applicable Territory carries **no exclusions** — there is no region where the license withholds use of the weights or their outputs. Two obligations still apply regardless of territory: a commercial product's interface must display "MiniMax-Music3" prominently, and a hosted deployment that serves the model to others takes on a safeguards duty (content-safety and misuse-prevention measures, per the license text) rather than the personal/direct-use posture of running it locally for yourself.
