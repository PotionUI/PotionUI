Make and edit pictures with the FLUX models hosted by Black Forest Labs, without needing a graphics card.

Pick a model, describe the picture and generate. In edit mode, add one or more pictures and describe the change you want: FLUX.1 Kontext, FLUX.2 and FLUX 3 Image keep what you do not ask to change. The controls you see follow what the chosen model can do, so a setting the model does not offer is simply not shown. Most models honour the seed, so the same seed and prompt give the same picture again.

Every picture is made on Black Forest Labs' side and billed to the administrator's BFL account. Your prompt and any pictures you add leave this server to do so.
