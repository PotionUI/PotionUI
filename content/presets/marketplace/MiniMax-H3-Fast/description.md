Generate a short video and its soundtrack together from one prompt, on FastVideo's **FastH3 8-Step V2** — a DMD2-distilled repack of MiniMax-H3 trained to produce a finished clip in exactly 8 denoising steps instead of the base model's 20-25. The picture and the audio come out of the same pass, so the sound matches what is on screen instead of being added afterwards. Optionally anchor the opening and closing frames with your own images. FastH3 runs at the same fixed 24 fps as the base checkpoint, for up to 15 seconds, and needs no guidance scale or negative prompt.

**Fixed 8-step speed profile.** Unlike the base MiniMax-H3 preset, there is only one speed profile here — distillation trains the checkpoint against exactly 8 steps, so unlike a general-purpose model there is no quality/speed trade-off left to expose as a choice. The Steps slider on the Advanced tab reflects this and stays locked.

**What's lost versus the base checkpoint.** FastVideo ships only an fl2va-shaped repack: there is no Reference mode here, and no ref2va checkpoint partition to distill against. The distillation itself trades some motion and audio fidelity for the 3x-fewer-steps speedup — expect a softer, less detailed result than a full 20-25 step render of the base model, in exchange for a much faster turnaround.

**Sparse attention is an approximation, not the real thing.** FastH3's checkpoint is trained toward VSA, a sparse-attention pattern baked into the model. VSA's own sparse routing is not ported into this preset's pipe yet — the Sparse attention section on the Advanced tab (SLA with a dense warm-up) is a best-effort approximation of that trained pattern using the sparse-attention mechanism the base preset already ships, not a reimplementation of VSA itself. Treat its defaults as a reasonable starting point, not a guarantee of matching FastVideo's own reference outputs.
