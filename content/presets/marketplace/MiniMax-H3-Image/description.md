Generate and edit images with MiniMax-H3-Image, MiniMax's image model built on the MiniMax-H3 transformer without its audio stream. It is distilled to six steps, so there is no guidance scale and no negative prompt, and it is tuned for about 2048×2048 pixels of area (4 to 16 megapixels work). **Edit** mode takes up to 16 pictures in order: Picture 1 is the image being edited, and the prompt can refer to the others as Picture 2, Picture 3 and so on.

The text encoder is the same Qwen3-VL-32B file MiniMax-H3 uses, so a machine that already runs MiniMax-H3 only needs the DiT and the MiniMax-H3-Image VAE. The int8 DiT stays resident on a 32 GB card; the text encoder is swapped in only when a prompt changes.
