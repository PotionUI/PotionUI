Make and edit pictures with hosted models from OpenRouter, without needing a graphics card.

Pick a model, describe the picture and generate. In edit mode, add one or more pictures and describe the change you want. The controls you see follow what the chosen model can do, so a setting the model does not offer is simply not shown.

Every picture is made on OpenRouter's side and billed to the administrator's OpenRouter account. Your prompt and any pictures you add leave this server to do so.
