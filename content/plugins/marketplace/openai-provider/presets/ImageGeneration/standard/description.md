Make and edit pictures with OpenAI's GPT Image models, without needing a graphics card.

Pick a model, describe the picture and generate. In edit mode, add the picture to change, optionally paint a mask on it to limit the change to that area, add more pictures as references if you like, and describe the change you want. The controls you see follow what the chosen model can do, so a setting the model does not offer is simply not shown.

Every picture is made on OpenAI's side and billed to the administrator's OpenAI account. Your prompt and any pictures you add leave this server to do so.
